# OilyGiant Mining Company – Oil Well Profitability Analysis

## Description
This project identifies the most profitable region for drilling new oil wells using regression and bootstrapping techniques.

## Dataset
Includes oil well characteristics and regional yield data.

## Methodology
- Data cleaning and preprocessing.  
- Built regression models to predict oil well yield.  
- Applied bootstrapping to estimate potential profits and risks.  

## Results
- Identified the best region for new well development.  
- Delivered insights to support investment decisions.
