# Video Game Sales Forecasting

## Description
This project predicts global video game sales using historical data and machine learning regression models. The goal is to identify factors influencing sales and build accurate forecasting models.

## Dataset
The dataset includes information about video games such as platform, genre, publisher, release year, and sales in different regions.

## Methodology
- **Exploratory Data Analysis (EDA)**: Analyzed distribution of sales by region, genre, and platform.  
- **Data Preprocessing**: Cleaned missing values, encoded categorical features, and normalized data.  
- **Modeling**: Trained regression models including Linear Regression, Random Forest, and Gradient Boosting.  
- **Evaluation**: Used RMSE and R² metrics to compare model performance.  

## Results
- Identified key features influencing video game sales.  
- Best-performing model achieved strong predictive accuracy for global sales forecasts.
