# Statistical Data Analysis

## Overview
This project applies statistical methods to analyze real-world data. The aim is to uncover meaningful relationships, test hypotheses, and support decision-making with evidence-based insights.

## Data
- Dataset includes numerical and categorical features.  
- Used for hypothesis testing and exploratory analysis.  

## Approach
1. **Data Preparation** – cleaned missing values, formatted data.  
2. **EDA** – descriptive statistics and visualizations.  
3. **Statistical Testing** – applied tests such as t-tests, chi-square, and correlation analysis.  
4. **Interpretation** – translated statistical findings into actionable conclusions.  

## Results
- Identified significant patterns and relationships.  
- Provided statistical justification for business insights.
