# Rusty Bargain – Used Car Price Prediction

## Overview
Built machine learning models to predict used car prices based on technical specifications and historical sales data.

## Data
- Features: age, mileage, engine size, condition.  
- Target: Car price.  

## Approach
1. **Data Preparation** – encoding, scaling, missing values.  
2. **Modeling** – Linear Regression, Decision Tree, Random Forest, LightGBM.  
3. **Evaluation** – RMSE and runtime analysis.  

## Results
- Best model achieved accurate predictions with fast runtime.  
- Useful for real-time pricing in Rusty Bargain’s system.
