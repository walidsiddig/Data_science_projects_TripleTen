# Customer Churn Prediction – Beta Bank

## Description
This project predicts customer churn for Beta Bank using machine learning classification models. The goal is to reduce churn through targeted retention strategies.

## Dataset
Customer demographics, account info, and service usage.

## Methodology
- Preprocessing and feature engineering.  
- Class imbalance handling.  
- Models: Logistic Regression, Random Forest, Gradient Boosting.  
- Metrics: F1 score and ROC-AUC.  

## Results
- Achieved F1 > 0.59.  
- Final model balanced fairness and accuracy.
