# Sure Tomorrow Insurance – Benefits Prediction

## Overview
Analyzed customer data to predict benefit eligibility, number of benefits, and similarities among clients. Also tested secure data masking.

## Data
- Demographics, insurance policies, claim history.  
- Target: Benefits eligibility/count.  

## Approach
1. **EDA** – customer patterns.  
2. **Clustering** – to find similar clients.  
3. **Regression** – predicted number of benefits.  
4. **Data Masking** – tested feature encryption.  

## Results
- Accurate benefit prediction.  
- Privacy-preserving analysis successful.
