# Gold Ore Recovery Prediction

## Description
This project predicts gold recovery rates at different processing stages using machine learning regression models.

## Dataset
Contains features from rougher and final concentration stages in the gold ore recovery process.

## Methodology
- EDA and process tracking.  
- Preprocessing: scaling, handling missing values.  
- Trained regression models (Random Forest, Linear Regression, etc.).  
- Evaluation with sMAPE metric.  

## Results
- Achieved accurate predictions of recovery rates.  
- Provided recommendations to improve production efficiency.
